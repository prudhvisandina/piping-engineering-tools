Piping Design Reference Data

An interactive, browser-based reference tool designed to help piping design engineers quickly access commonly used piping dimensions, technical data, and preliminary engineering calculations.

Features

Pipe Dimensions: NPS, DN, outside diameter, wall thickness, inside diameter, and pipe weight for various schedules.

Flange Dimensions: Reference dimensions for ASME B16.5 flanges across supported pressure classes.

Butt-Weld Fittings: Reference dimensions for ASME B16.9 elbows, tees, reducers, and caps.

Socket-Weld Fittings & NPT: Selected dimensional data for ASME B16.11 fittings and ASME B1.20.1 pipe threads.

Gaskets: Selected spiral-wound gasket dimensions based on ASME B16.20.

Pressure–Temperature Ratings: Reference data for selected ASME B16.5 material group and pressure classes.

Pipe Support Spans: Selected suggested support-span reference data.

Pipe Spacing: Interactive reference for piping spacing considerations.

Valve Access: Reference information for valve accessibility and maintenance clearances.

Engineering Calculators: Built-in calculators for common piping design reference calculations and unit conversions.

Metric and Imperial Units: Switch between millimetres and inches.

Interactive Tables: Select and highlight a nominal pipe size across relevant reference tables.

Responsive Interface: Technical tables and layouts designed for browser-based use.

Technology

HTML5

CSS3

JavaScript

SVG-based technical diagrams

The website is provided as a self-contained HTML file and is intended to run directly in a modern web browser.

How to Use

Open the website in a modern web browser.

Select the required reference section using the navigation tabs.

Choose the nominal pipe size (NPS) and applicable options.

Switch between metric and imperial units as needed.

Use the displayed dimensions and calculations as preliminary engineering references.

Deployment

This project can be hosted using GitHub Pages or another static website hosting service.

Disclaimer

This website is an engineering reference aid and is not a substitute for official standards, approved project specifications, manufacturer documentation, or engineering verification.

Always verify dimensions, ratings, calculations, and design requirements against the applicable current edition of the relevant standard and the project's approved piping class before using the information for design, fabrication, procurement, or construction.

The accuracy and applicability of the displayed data should be independently verified by the user.
